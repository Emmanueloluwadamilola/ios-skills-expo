# ios-skills-expo

Expo & EAS best-practice skills for building, deploying, and upgrading Expo / React Native apps.

> **Curated mirror** of [https://github.com/expo/skills](https://github.com/expo/skills) by **Expo Team**. All credit to the original
> author. See [ATTRIBUTION.md](./ATTRIBUTION.md). Contains **24** skill(s).

## Install (Claude Code)

```bash
claude plugin marketplace add Emmanueloluwadamilola/ios-skills-expo
claude plugin install ios-skills-expo@ios-skills-expo
```

## Install (any agent)

```bash
git clone https://github.com/Emmanueloluwadamilola/ios-skills-expo.git
cp -R ios-skills-expo/plugins/ios-skills-expo/skills/* ~/.agents/skills/
```

Each folder under `plugins/ios-skills-expo/skills/` is a self-contained skill you can also
install individually.
